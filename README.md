# questions

本仓库用于课后作业的框架代码归集与版本管理。

## 仓库约定

- 默认主分支：`main`，仅存放 README 等初始化记录，不承载业务代码。
- 开发分支：`dev/<题号>`，业务代码、测试、原型、约束、Skill、配置及文档变更均在该分支提交与推送。
- 当前已建立的开发分支：

| 开发分支 | 负责题号 | 说明 |
| --- | --- | --- |
| `dev/1` | 题号一 | 框架源码（bw-cli-main） |

## 分支使用方式

```bash
# 拉取指定题号的开发分支
git clone -b dev/1 https://github.com/Yolo1217/questions.git
```
