六场景复现路径

场景页面操作
S1 正常成交买家下单 → 模拟渠道支付 → 仓库发货登记 → 买家查看运单
S2 缺货与弃单买家连续下单直至缺货提示 → 取消未支付订单 → 库存回补后他人可下单
S3 售前退款买家申请退款 → 仓库尝试发货被拒 → 客服审核同意（首次失败后重试）
S4 迟到支付下单后等待超时关单（可用 TRADE_KEEP_SECONDS 缩短）→ 再点“再推一次”支付 → 客服异常处置
S5 操作竞争两个买家/客服并发操作同一订单，仅一方生效；越权访问返回 401/403
S6 运营核查运营工作台核对收款/退款/可售/预占与台账合计一致
